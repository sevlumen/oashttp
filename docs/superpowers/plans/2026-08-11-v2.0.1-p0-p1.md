# v2.0.1 P0-P1 Implementation Plan

> This plan records the implementation and release-review work completed on `feat/v2.0.1-p0-p1`. Merge, tag, and GitHub Release publication remain separate explicit steps.

**Goal:** Deliver an additive v2.0.1 candidate with corrected support policy, raw `http.Handler` integration, scoped middleware, request-scoped observability metadata, and named security providers.

**Architecture:** Extend the existing operation definition/compiler instead of introducing a second router. Typed and raw operations share registration, OpenAPI metadata, security, request state, and scoped middleware; typed operations retain compiled binding/validation while raw operations retain direct `*http.Request` ownership. Legacy bearer authentication remains backward-compatible rather than being replaced.

**Tech Stack:** Go 1.22+, standard `net/http`, existing internal OpenAPI 3.1 model, GitHub Actions CI.

## Global Constraints

- No third-party runtime dependencies.
- Preserve existing v2 public behavior and legacy bearer/OpenAPI defaults.
- New APIs are additive.
- OAuth2/OpenID Connect flows and first-class scopes remain out of scope for v2.0.1.
- Raw handlers must not cause the core library to parse or buffer streaming bodies.
- Follow RED/GREEN testing for behavior changes.
